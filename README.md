# Burn Rate

A solid rocket motor design game by **Longlight Interactive**. Rent a stand at a decommissioned Cold War test range,
design a motor to a client's spec, watch the predicted curve, then fire it for real and find out why it didn't match.

Play: https://burnrate.longlight.games/ (phone first, works offline once installed).

- Plan: `docs/BURN-RATE-PLAN.md` · progress: `docs/PROGRESS.md` · notes for contributors: `CLAUDE.md`
- Build: `node build.js` (no dependencies) · checks: `node build.js --check`, `node tools/sim-test.js`
